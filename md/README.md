# Academic Advisor Appointment System - Login Implementation

## Overview
This is a professional login system for the Academic Advisor Appointment System. It features secure password authentication using SHA-256 hashing, session management, and a modern, responsive user interface.

## Features

### Security Features
- **Password Hashing**: Uses SHA-256 algorithm with Base64 encoding for secure password storage
- **Session Management**: Automatic session timeout after 30 minutes of inactivity
- **Input Validation**: Server-side and client-side validation for username and password
- **Secure Credentials**: User database implemented using Hashtable data structure

### UI Features
- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Modern Interface**: Gradient backgrounds, smooth animations, and intuitive layout
- **Password Visibility Toggle**: Show/hide password functionality for user convenience
- **Error Handling**: Clear, user-friendly error messages for login failures
- **Demo Credentials**: Test credentials provided for demonstration purposes

### User Management
- **User Database**: Hashtable-based storage for user credentials
- **Multiple User Roles**: Admin, Advisor, and Student accounts
- **Session Tracking**: Login time and session ID tracking

## Technical Details

### LoginServlet.java
The main servlet that handles user authentication:

- **URL Pattern**: `/LoginServlet`
- **Methods**:
  - `init()`: Initializes the user database with sample credentials
  - `doGet()`: Redirects to login.jsp
  - `doPost()`: Processes login requests
  - `hashPassword()`: Converts plain text password to SHA-256 hash
  - `verifyPassword()`: Validates password against stored hash

## Security Best Practices Implemented

1. **Password Hashing**
   - Passwords are never stored in plain text
   - SHA-256 algorithm with Base64 encoding
   - Hash verification during login

2. **Session Management**
   - Session ID generated by servlet container
   - Automatic timeout after 30 minutes
   - Session invalidation on logout

3. **Input Validation**
   - Client-side validation for immediate feedback
   - Server-side validation for security
   - Trimming of whitespace to prevent bypass attempts

4. **Error Handling**
   - Generic error messages to prevent information disclosure
   - No indication of which field is incorrect
   - Error logging for debugging

5. **HTTPS Ready**
   - Code structure supports HTTPS deployment
   - Secure session cookie flags ready for production

## Troubleshooting

### Issue: Compilation Errors with Servlet Imports
**Solution**: Ensure Tomcat or Glassfish server libraries are added to project classpath
- In NetBeans: Right-click project → Properties → Libraries → Add Library → Apache Tomcat

### Issue: Login Page Not Loading
**Solution**: 
- Verify server is running
- Check URL matches context path
- Check WEB-INF/web.xml configuration

### Issue: Session Not Persisting
**Solution**:
- Clear browser cookies
- Ensure cookies are enabled
- Check server session timeout settings
